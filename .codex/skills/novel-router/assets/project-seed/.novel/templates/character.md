# 人物档案模板

共用元数据：record_id / record_type / truth_status / lifecycle / source_ref / valid_from / depends_on / supersedes。格式见 .novel/schemas/story-record.md。

## 稳定档案
- identity / history / external_goal / inner_need：身份、过往、欲望和需求。
- fear / values / limits / voice_profile：恐惧、价值观、底线与语言差异。
## 动态条目
- state_intervals：有效时段、来源、地点、伤势/限制、体力。
- relationships / knowledge：各关系维度，知道/怀疑/误信及获知来源。
- possessions / promises：物品转移、承诺与债务。
- before / after / reason：变化前后与原因。
lifecycle：proposed / present / absent / deceased。知情状态不可倒灌早期场景。

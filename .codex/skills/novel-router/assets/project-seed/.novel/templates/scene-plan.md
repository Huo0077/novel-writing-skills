# 场景计划模板

plan_id / plan_type=scene / plan_status / revision / approval_ref / source_ref / based_on。
- viewpoint / location / time_window / participants：视角、时空、人物。
- entry_state / goal / obstacle / choices / cost：入口、目标、阻力、选择和代价。
- target_delta / exit_condition：预期变化与具体结束条件。
- reveal_budget / public_packet_ref：揭示预算与公开包。
- sensory_anchor / emotional_distance：可选细节锚点与情绪距离。
- voice_refs / limits / handoff：声音资料、不能做的事及交接。
注意安静场景可以有情绪/关系功能，不硬造事件。详见 planning-contract.md。

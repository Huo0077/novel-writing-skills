# 初始化提问顺序

按需推进，不必一次完成所有阶段。

## 阶段一：项目身份

询问：作品名称、类型/子类型、目标篇幅、预期读者、创作者选择的工作模式。

## 阶段二：故事核心

询问：一句话 premise、主角、核心欲望、主要阻力、故事要追问的主题问题，以及哪些内容绝不能出现。

## 阶段三：事实边界

询问：哪些内容已经确定为正史；哪些只是灵感、候选或待决定；是否存在外部原稿、设定集或参考资料。

## 阶段四：结构骨架

询问：主线方向、阶段性目标、已知关键事件、结局确定程度、当前进度。

## 阶段五：重点档案

根据当前写作任务，只补齐相关人物、地点、规则、时间线或伏笔，不要求一次填完全部档案。

## 每轮输出

- 已确认的 `CANON`
- 暂存的 `TENTATIVE` 或 `PROPOSAL`
- 尚未确定的关键空位
- 下一轮最有价值的问题
- 当前可以安全执行的任务

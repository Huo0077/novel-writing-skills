# 渐进初始化提问

先读已有资料，以下为问题池，不是一次全部询问。每轮只问一个影响当前任务的关键点；用共享clarification-contract记录用户答案，给2–3个方向、短后果、自定义/暂不决定。

## 第一阶段：任务和合作

当前要从零规划、导入旧稿，还是续写已有作品？先确定该入口；之后必要时问合作模式。
ABC模式分别说明作者掌控、AI提案主动程度、批量推进边界；高风险暂停在三模式一致，不虚构已选择。

## 第二阶段：最小故事起点

主角当前想解决什么问题？给不同功能方向例如救人/查证/维系关系，只作建议，不据此强补世界或终局。名字/体裁已有答案不再问。

## 第三阶段：已有事实

明确哪些用户内容是已确定、待试或灵感；若冲突先核当前一点。导入原稿时先回审来源，不一次让用户填完所有人物。

## 第四阶段：当前结构

按需求逐步补当前阶段目标、场景前状态、局部冲突、揭示门槛；远期结局允许unknown。

## 第五阶段：领域缺口

世界/人物/时间/伏笔问题只补当前相关档案，选择后记录来源与作用范围。部分回答只更新部分，不自动批准整套候选。

## 每轮结果

已获得答案、对应档案/提案、仍未知、当前blocked/可继续安全任务。不得在用户未回答时用推荐项自动建CANON。

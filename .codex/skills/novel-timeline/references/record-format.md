# 时间段记录
record_type=timeline；lifecycle=planned/occurred/disputed。
字段：calendar、start、end、precision、uncertainty、participants、location、travel_mode、travel_lower_bound、travel_source、before_ids、parallel_ids、narration_position。
候选：proposals/timeline-<id>.md。批准后 novel-canon 更新 canon/timeline.md。
约束例：A 最早离开时间 + 已确认最短行程 > B 最晚到达时间，则行程冲突。
耗时未知不可断言不可能。18:00结束和18:00开始是否冲突看地点与具体活动，不机械判断边界重叠。
段落相邻不等于同时，换章不自动过去一天。

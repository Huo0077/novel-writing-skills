# 世界规则记录
record_type=world；lifecycle=proposed/active/retired；truth_status 沿用共享真值标签。
字段：rule、scope、preconditions、prohibited_actions、costs、exceptions、exception_sources、belief_versions、known_by、reader_evidence、scene_function、open_questions。
候选：proposals/world-<id>.md。批准后由 novel-canon 更新 canon/world.md。
每条例外都需适用条件与来源；unknown 不是通行许可。代价不能只写在百科里，正文实际支付需事件来源。
confirmed_conflict：事实与规则直接冲突；possible_conflict：条件或代价尚不明；insufficient_information：仅传闻/角色说辞或缺前提。
新增影响后续的规则通常中风险，修改核心限制或谜题解法高风险。

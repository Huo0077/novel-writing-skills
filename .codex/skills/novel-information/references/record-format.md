# 信息项与公开包
record_type=information；lifecycle=hidden/hinted/partial/revealed。
作者字段：author_truth、truth_source、truth_confirmed、character_beliefs（时间/状态/来源）、reader_evidence、narrator_permission、reveal_gate、earliest_reveal、risk。
公开字段：audience=draft_writer/reader_test、viewpoint、allowed_facts、visible_clues、forbidden_operations、unresolved_questions、source_window。
forbidden_operations 用 do_not_reveal:I-001，不用“别写守门人帮助过母亲”这种本身泄漏答案的指令。
候选：proposals/information-<id>.md；批准后 novel-canon 更新 canon/information-map.md。公开包可写 planning/scenes/<id>-public.yaml。
盲测材料不含 author_truth、答案词表、预期解释、伏笔标签、作者意图；不先加载完整作者档案。

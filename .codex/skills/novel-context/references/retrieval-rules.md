# 上下文检索规则

## 必须读取

- `.novel/project.yaml`
- 最近的 `.novel/checkpoints/` 检查点
- 当前模式和风险规则
- 当前任务明确提到的实体
- 当前场景前状态和相关计划

## 按依赖读取

- 角色任务：人物动态状态、关系、已知信息和行为底线。
- 世界任务：相关世界规则、例外和违反后果。
- 事件任务：事件因果、时间线、地点和并行行动。
- 伏笔任务：读者认知、角色认知、显眼度和禁止揭示项。
- 修订任务：原文、回审报告、状态变更和下游影响列表。

## 上下文上限

优先使用摘要、状态字段和当前窗口；只有当局部信息不足以判断时，才扩大读取范围。扩大范围时记录原因。

## 缺失事实

缺失事实应写入 `uncertainties`，并指出需要向创作者确认的问题。不得用概率最高的猜测伪装成 CANON。

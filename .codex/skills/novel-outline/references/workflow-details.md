# 总纲细化

采用 planning-contract 共用字段。领域：premise、theme_question、planning_horizon、stage_questions、arcs、promises、payoff_windows、dependencies、author_notes、open_questions。
每阶段注明 current_problem / what_changes / costs / questions_remaining。支线可以服务关系或主题，不要求全部立即连主谋。
修订时标受影响章节与 source_ref；未发生未来计划不能倒灌人物当前认知。
交接 novel-chapter-plan：只给当前阶段约束。章规划若作为作者任务可读隐藏答案，正文任务只接收到批准公开切片。
默认一份当前规划，不提供几十个无依据分支。创作者核心目标未定时停在可讨论结构，而非虚假“完成”。

# 可执行场景

plan_type=scene。字段：viewpoint、location、time_window、participants、goal、obstacle、choices、cost、public_packet_ref、voice_refs、limits。
entry_state 与人物档案引用相应有效时段。target_delta 留计划预期。exit_condition 应能从正文观察是否达到。
公开任务可以载有限目标，但不能载作者解答。声音资料须筛掉人物私密心理真相和未来口供。
批量默认一场；创作者批准多场时明确边界、上下游依赖与每场检查点。中风险未确认前仅在标注候选分支内前进。
缺公共包可先在作者分析阶段制作；普通 writer 不临时读取隐藏档案“自己补”。

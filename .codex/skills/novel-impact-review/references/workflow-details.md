# 影响报告
字段：change_ref、change_type、before/after、coverage(read_sources/not_read/unresolved_sources)、downstream_impact、whole_novel_verified、creator_decision。
每项影响含entity_ref/source_ref、dependency_path、certainty、required_action。
图路径例：新报告承诺→人物承诺状态→下章拒绝报告场景→关系变化。没读取后文则“需要核查”，不可写已矛盾。
若改右手动作但保留骨折，查紧邻动作；若把骨折取消，查恢复时间、战斗限制、人物依赖等更广范围。

# 伏笔线索模板

共用元数据：record_id / record_type / truth_status / lifecycle / source_ref / valid_from / depends_on / supersedes。格式见 .novel/schemas/story-record.md。

- secret_ref：作者真相引用（仅作者包）。
- surface_function / scene_goal / carrier：当前功能、场景目标与载体。
- first_source / visible_detail：首次来源和读者可见细节。
- character_interpretation / competing_explanations：人物解释及有依据的竞争解释。
- true_interpretation：真实解释与既有证据的兼容（仅作者包）。
- salience / next_window / reveal_gate：主观显眼度、下一窗口与揭示条件。
- retrospective_change / consequence：回看新含义与揭示后果。
- test_status：not_tested / manual_rehearsal / independent_test。
lifecycle：planned / planted / advanced / paid_off / abandoned。普通象征不强制制造两个误导答案。

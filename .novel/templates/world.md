# 世界规则模板

共用元数据：record_id / record_type / truth_status / lifecycle / source_ref / valid_from / depends_on / supersedes。格式见 .novel/schemas/story-record.md。

- rule / scope / preconditions：规则、范围和前提。
- prohibited_actions / costs：限制、代价与违反后果。
- exceptions / exception_sources：例外与证据。
- belief_versions：传说、制度说辞与客观机制的区别。
- known_by / reader_evidence：角色知道什么、读者看到什么。
- scene_function / open_questions：当前功能和未知。
lifecycle：proposed / active / retired。

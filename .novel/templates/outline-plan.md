# 总纲模板

plan_id / plan_type=outline / plan_status / revision / approval_ref / source_ref / based_on。
- premise / theme_question：故事命题与核心追问。
- scope / length_preference / planning_horizon：篇幅范围与滚动规划长度。
- stage_questions：卷/篇章的当前问题、核心冲突呈现层级。
- arcs / dependencies：人物弧光与事件依赖。
- promises / payoff_windows：承诺、伏笔回收窗口。
- reveal_budget / author_notes：允许增量和作者真相（分开）。
- entry_state / target_delta / exit_condition / handoff：起点、目标变化与交接。
- open_questions：只询问当前阻塞项；未知结局不强补。
详见 .novel/schemas/planning-contract.md。

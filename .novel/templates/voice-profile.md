# 人物声音模板

profile_id / character_ref / truth_status / source_ref / valid_from。
- attention：首先注意什么，哪些细节会忽略。
- vocabulary_domain / syntax：词域、句法与节奏倾向。
- speech_strategy / avoidance：索求/防御/回避的社交策略。
- addressed_to / formal_context / under_pressure：对谁说、场合差异与压力变体。
- knowledge_refs / forbidden_claims：可知信息与不能断言的事。
- catchphrase：未知写 unknown，不必发明口癖。
- anchors / counterexamples：创作者原句/已确认对白与反例。
- proposed_traits：新特征先候选，不写入核心人格。
语言差异不靠所有句子同一长度，也不靠刻板身份/地域印象。

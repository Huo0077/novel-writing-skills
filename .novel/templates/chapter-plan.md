# 章节计划模板

plan_id / plan_type=chapter / plan_status / revision / approval_ref / source_ref / based_on。
- chapter_function / reader_question：本章功能与读者当前问题。
- entry_state / target_delta：入口与预期变化。
- scene_ids / scene_dependencies：场景序列、依赖与删场影响。
- tension_curve / aftermath：压力变化、停顿和后果消化。
- reveal_budget / setup_payoff：信息增量与伏笔窗口。
- exit_condition / next_safe_action / handoff：何时收束与下一步。
不强制每章高潮、反转或神秘尾句。详见 .novel/schemas/planning-contract.md。

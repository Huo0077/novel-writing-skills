# 审查报告模板

audit_id / scope / coverage / source_ref / version。
- findings：ID、类型、证据位置、判断强度、严重性、原因。
- repetition_class：effective / suspicious / ineffective（表达项）。
- protection_decision：keep / clarify / revise。
- smallest_fix：不改正史的最小修复。
- creator_questions：当前关键阻塞问题。
- next_action：修订/确认/补资料，不谎称全文已验证。
见 .novel/schemas/audit-revision-contract.md。

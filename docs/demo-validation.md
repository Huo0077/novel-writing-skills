# README 演示优化与验收

日期：2026-10-14。范围：演示页面、静态导出和双语README，不改变skills或已发布版本。

## 原始问题复现

- README的docs/demo.html相对链接在GitHub打开源码页，不是执行网页；当时对应Pages地址404。
- 外部Tailwind runtime无法加载时，页面无样式，桌面舞台高度达到约5632像素。
- 声称70秒/1080P，实际GIF8.25秒、840×472；MP410秒、1200×674、FMP4编码。
- 字小、信息密集，部分文案夸大自动全书审查/盲测保证；原视频没有证明相应能力。

## 本次处理

演示改成36秒、4场景：写作问题→对照依据→询问作者→修订回审。标明流程示意、非模型实录。无外部CDN/字体/分析依赖；默认暂停、无声。
中英文切换、播放/暂停、时间拖动、章节跳转、键盘操作和桌面全屏；手机使用单列并保留可读字号。
GIF是12秒摘要，不冒充完整视频；主视频H.264/yuv420p、1280×720、24fps、36秒、faststart。中文/英文各自导出。
README动图链接到GitHub Pages执行页面，不链接HTML源码；完整MP4在播放页或直链打开，README不塞被净化的脚本/iframe。
新导出使用新文件名，避免旧GIF/视频缓存混淆。原HTML与原有GIF/MP4保留，原稿备份在本地，不破坏历史链接。

## 实际验收

- 14项Node演示测试通过，含时间边界、双语字段、无远程runtime、README链接、媒体字节/尺寸、H.264/faststart和真实进度条回归。
- 进度条曾因pause重渲染先重置value而失效；浏览器复现后新增2项失败回归，修复为先捕获用户请求时间，再暂停并seek，回归通过。

- 本地页面没有外部资源请求或脚本错误；视频加载/语言切换中的主动取消不当作网络故障。
- 原技能完整148案例：147通过、1个Python符号链接权限项跳过、0失败。

# v1.2 标准技能安装与作品初始化计划

用户已确认实施和更新README/Release；在当前任务执行，不启用代理。

目标：以npx skills add复用标准分发，不新发npm注册包；提供随router安装的零依赖Node作品初始化，按真实目录定位资源，保留用户作品。

## 范围与边界
- 仍31技能；源仓库技能保留.codex/skills布局以维持历史和开发测试。
- 标准安装选择全31项，推荐--copy避免符号链接依赖；Codex标准安装输出.agents/skills，以实测CLI版本为准。
- Node当前工具要求22.20+（本次实测skills@1.7.2的要求）；Python/PyYAML仅用于可选的既有审查工具/开发验收，不是首次初始化前提。
- 不自动执行postinstall、不扫描/复制真实小说、不替换用户文件、不修改全局shell/包源、不执行卸载作品。
- 默认初始化预览，--apply仅创建缺失项目种子，--check只读检查技能/共享资源是否齐全；目标由--target或cwd决定，不由全局skill目录推导。
- 全局技能安装不自动产生作品；卸载skill后.novel仍保留。完整Python开发测试在仓库运行，安装项目使用Node --check，不能假装122固定测试已分发为用户数据。

## 新增文件与接口
novel-router/scripts/init-project.mjs：exports inspectInstallation(routerPath)、initializeProject({routerPath,target,apply})、main(argv)；import.meta定位router，preview/apply/check三状态。
novel-router/tests/test-init-project.mjs：node:test，临时目录中的文件保留、全局源/当前作品分离、缺模块、目录冲突、错误参数、重复执行及路径越界；先写失败再实现。
novel-router/tests/test-portable-suite.py：Python补充.agents技能集合定位/打包规范，集成原suite --tests。
修改suite.py查找.codex/.agents/.claude集合，打包.mjs/PNG/LICENSE/双语README，确保MIT随新包。
全部SKILL.md加“技能路径相对已安装位置、项目资料相对作品根目录”规约；移除跨skill硬编码.codex引用。router/project-init/operations补Node初始化步骤和安全边界。
新增package.json仅private开发脚本（npm test），不提供虚假的registry已发布命令或npm publish；Node无需三方依赖。
更新中英README/快速开始/使用指南以npx安装为主；支持交互安装与明确选全量命令。

## 执行
1. 获取npx skills实际版本和发现/复制行为，记录Node/npm/skills环境，先跑本地source list。
2. 编写Node及Python先行失败测试。
3. 实现初始化+资源定位+包资源；同步shared seed，仅协议模板，真实故事不动。
4. 在隔离project与受控HOME目录通过标准安装器安装，运行实际安装的Node preview/apply/check；global不写真实用户home。
5. 检查已填作品字节不变、初始化两次零新增、缺技能明确报错；卸载测试仅在临时隔离项目，不调用破坏用户全局目录。
6. 全组旧+新测试、文档路径命令检查、LICENSE/图片出包检查。Windows软链接权限跳过项如实记录。
7. 打包v1.2；先推main候选以便从GitHub真实npx安装，安装通过后再打v1.2标签/发布。不得重写历史标签/ZIP。
